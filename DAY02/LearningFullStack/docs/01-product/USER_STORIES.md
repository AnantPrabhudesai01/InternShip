# USER_STORIES (MVP slice)

- Visitor: explore landing → register/login.
- New user: verify email → onboard → create/join workspace → dashboard.
- Owner: configure workspace → invite → create project.
- PM: backlog → sprint → assign → monitor → analytics.
- Dev: view task → comment/mention → upload → move status → complete.
- Reviewer: inspect → comment → approve/request changes.
- AI user: ask → context retrieved → cited answer → propose tool → confirm → execute → audit.

Each story needs acceptance + loading/empty/error states per Definition of Done.
