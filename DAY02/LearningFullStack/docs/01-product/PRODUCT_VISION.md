# PRODUCT_VISION — AI DevFlow

## One-line

A collaboration + project platform where project context is searchable, summarized, and actionable by permissioned AI.

## Problem (see PROBLEM_STATEMENT.md)

Teams lose context across tasks, sprints, docs, comments. Generic AI chat can't read project data or act safely.

## Users

Developers, PMs, reviewers, workspace owners, visitors, AI-assisted users.

## Value

- Single source: workspace→project→sprint→task→comment→doc→activity.
- Realtime Kanban + discussions + notifications.
- AI that solves real jobs: generate tasks, plan sprints, summarize threads, answer from docs (RAG + citations), propose tool actions with confirmation + audit.

## Non-goals (MVP)

No microservices, no Kafka/K8s, no complex billing, no multi-LLM orchestration v1.

## Success (portfolio)

Vertical slices done per Definition of Done; AI features gated + audited; docs↔code in sync; measured (not invented) test/perf results.
