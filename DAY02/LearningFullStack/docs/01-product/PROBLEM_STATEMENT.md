# PROBLEM_STATEMENT

## Core Problem

Dev teams split work across issues, docs, chat, and static boards. Context is hard to retrieve; newcomers repeat questions; leads manually break down work and summarize threads.

## Evidence

`ASSUMPTION` — validated by building MVP with real seed data + dogfooding; no external claims made.

## Why Existing Tools Fall Short for This Portfolio

Generic boards + detached chatbots: no permissioned retrieval over project docs/comments/tasks, no proposed-then-confirmed actions, no audit.

## What Good Looks Like

Ask "what blocks release X?" → cited answer from tasks/sprints/comments/docs; "plan sprint from backlog Y" → draft tasks for review; "summarize thread" → decision + owners; all tool writes confirmed + logged.
