# TARGET_USERS

1. Visitor — evaluates, registers/logs in.
2. New user — verifies, onboards, creates/joins workspace.
3. Workspace owner — configures workspace, invites, creates projects.
4. Project manager — backlog, sprints, assignment, progress/analytics.
5. Developer — assigned work, comments, uploads, status moves.
6. Reviewer — inspects, comments, approves/requests changes.
7. AI user — any above using AI assistance with confirmations.

Needs: low-friction onboarding, clear Kanban, fast search, trustworthy AI with sources + undo/confirm.
